# ReadVault — 微信读书助手
基于微信读书官方 Skill 开发

## 产品定位
轻量化 Web 工具，用于：
- 查看书架
- 查看笔记与划线
- 一键导出 Markdown / TXT
- 阅读数据统计
- 发现好书（推荐 / 热门划线 / 点评）

## 核心功能

| 序号 | 功能 | 状态 | 说明 |
|------|------|------|------|
| 1 | 微信读书授权 | ✅ | 通过官方 Skill API Key 验证 |
| 2 | 书架展示 | ✅ | 展示电子书、有声书列表，支持进度/状态筛选 |
| 3 | 笔记与划线 | ✅ | 查看单本书的笔记、划线、想法，支持搜索 |
| 4 | Markdown 导出 | ✅ | 一键导出笔记为 Markdown |
| 5 | TXT 导出 | ✅ | 一键导出笔记为纯文本 |
| 6 | 阅读统计 | ✅ | 周/月/年/总计模式，阅读天数、时长、偏好分析、热力图 |
| 7 | 书籍详情 | ✅ | 封面、评分、简介、章节目录、阅读进度环 |
| 8 | 书籍搜索 | ✅ | 支持多 scope（电子书、网文、作者等） |
| 9 | 个性化推荐 | ✅ | 为你推荐、编辑精选 |
| 10 | 相似书推荐 | ✅ | 基于当前阅读推荐相似书籍 |
| 11 | 热门划线 | ✅ | 展示全书热门划线及划线人数 |
| 12 | 公开点评 | ✅ | 查看读者点评（星级、内容、头像） |
| 13 | 笔记搜索 | ✅ | 在笔记中搜索关键词 |
| 14 | 数据缓存 | ✅ | 5～10 分钟本地缓存，减少重复请求 |
| 15 | 深色主题 | ✅ | 亮色/暗色主题切换，状态持久化 |
| 16 | 响应式网页 | ✅ | 适配 PC/平板/移动端 |

## 后续功能规划

### Phase 2.1 — 增强现有页面（短期）

| 功能 | 详情 |
|------|------|
| **统计页增强** | 利用 `/readdata/detail` 已返回但未展示的字段：偏好作者排行榜（`preferAuthor`）、24 小时时段分布（`preferTime`）、文字/听书比例（`readRate`/`wrReadTime`/`wrListenTime`） |
| **划线想法浏览** | 热门划线列表增加展开按钮，调 `/book/readreviews` 获取其他读者对此划线的想法 |
| **深度链接跳转** | 书架卡片加 `weread://reading` 链接、笔记划线加 `weread://bestbookmark` 链接，点击跳微信读书 App |

### Phase 2.2 — 新页面/新能力（中期）

| 功能 | 详情 |
|------|------|
| **个人阅读仪表盘** | 新页面聚合阅读概况：书架统计、最近笔记、阅读趋势、偏好分析，一站式概览 |
| **PDF 导出** | Notes 页增加 PDF 导出选项，浏览器端生成 PDF 文件 |
| **笔记本地标签** | 基于 IndexedDB 的本地标签系统，给笔记/划线打标签、按标签筛选 |

### Phase 2.3 — 体验提升（长期）

| 功能 | 详情 |
|------|------|
| **阅读目标追踪** | 本地设置年度/月度阅读目标，统计页展示完成进度 |
| **离线 PWA** | Service Worker 缓存，无网络时查看已缓存的书架和笔记 |

## 不做的功能

| 功能 | 原因 |
|------|------|
| 存储用户数据到服务器 | 隐私安全考虑，仅本地存储 |
| 全文下载 / 盗版分发 | 版权保护 |
| 笔记编辑/删除/新增 | Skill 为只读模式，无写接口 |
| 书架管理（增删改） | Skill 为只读模式，无写接口 |
| 社交功能（好友、读书圈、分享） | Skill 未提供社交类接口 |
| 书籍购买 / 会员 | 涉及支付，复杂度高 |
| 原生 APP | 专注 Web 端轻量化工具 |
| 有声书播放 | Skill 未提供音频流接口 |
| 阅读挑战 / 排行榜 | Skill 未提供挑战类接口 |
