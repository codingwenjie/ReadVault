# ReadVault — 微信读书助手
基于微信读书官方 Skill 开发

## 产品定位
轻量化 Web 工具，用于：
- 查看书架
- 查看笔记与划线
- 一键导出 Markdown
- 阅读数据统计

## 核心功能（MVP）

| 序号 | 功能 | 状态 | 说明 |
|------|------|------|------|
| 1 | 微信读书授权 | ✅ | 通过官方 Skill API Key 验证 |
| 2 | 书架展示 | ✅ | 获取并展示电子书、有声书列表 |
| 3 | 笔记与划线 | ✅ | 获取单本书的笔记、划线、想法 |
| 4 | Markdown 导出 | ✅ | 一键导出笔记为 Markdown |
| 5 | 阅读统计 | ✅ | 阅读时长、阅读天数统计 |
| 6 | 响应式网页 | ✅ | 适配 PC/平板/移动端 |

## 潜在新功能建议

### 1. 社交阅读功能

| 功能 | 描述 | 优先级 | 技术实现 |
|------|------|--------|----------|
| 书籍分享 | 一键分享书籍到微信/朋友圈 | 中 | 通过微信分享 API |
| 阅读小组 | 创建/加入阅读小组，共同阅读 | 低 | 需要后端支持小组管理 |
| 好友推荐 | 查看好友正在阅读的书籍 | 中 | 通过 API 获取好友动态 |
| 书评互动 | 点赞、评论他人书评 | 低 | 需要社交接口支持 |

### 2. 个性化内容推荐

| 功能 | 描述 | 优先级 | 技术实现 |
|------|------|--------|----------|
| 为你推荐 | 基于阅读历史的个性化推荐 | 高 | 调用 `/book/recommend` |
| 相似推荐 | 基于当前书籍推荐相似书籍 | 高 | 调用 `/book/similar` |
| 分类推荐 | 按分类浏览推荐书籍 | 中 | 搜索 API + 分类筛选 |
| 热门榜单 | 展示书籍排行榜 | 中 | 需要榜单接口 |

### 3. 高级笔记功能

| 功能 | 描述 | 优先级 | 技术实现 |

| 笔记搜索 | 在笔记中搜索关键词 | 中 | 前端搜索 |
| 笔记导出 | 支持多种格式导出（MD/TXT/PDF） | 高 | 前端生成文件 |
| 热门划线 | 查看书籍热门划线 | 中 | 调用 `/book/bestbookmarks` |

### 4. 阅读进度追踪

## 功能优先级矩阵

### 优先级定义
- **P0（高）**：核心功能，必须实现
- **P1（中）**：重要功能，提升用户体验
- **P2（低）**：辅助功能，可选实现

### 功能优先级表

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 个性化推荐（为你推荐） | P0 | 提升发现好书的体验 |
| 相似书推荐 | P0 | 基于当前阅读推荐 |
| 笔记搜索 | P0 | 快速定位笔记内容 |
| 多格式导出 | P0 | 满足不同导出需求 |
| 阅读日历 | P1 | 可视化阅读习惯 |
| 数据缓存/离线查看 | P1 | 提升离线体验 |
| 主题切换 | P1 | 适配不同使用场景 |
| 书籍搜索 | P1 | 快速查找书籍 |
| 热门划线 | P1 | 发现书中精彩内容 |
| 书籍分享 | P2 | 社交分享功能 |
| 有声书播放 | P2 | 扩展内容形式 |
| 阅读目标 | P2 | 激励用户阅读 |
| 阅读挑战 | P2 | 增加互动性 |

## 不做的功能

| 功能 | 原因 |
|------|------|
| 存储用户数据 | 隐私安全考虑，仅本地存储 |
| 全书下载 | 版权保护，禁止盗版分发 |
| 社交功能（深度） | MVP 阶段专注核心阅读体验 |
| 原生 APP | 专注 Web 端轻量化工具 |
| 书籍购买 | 涉及支付，复杂度高 |
| 笔记编辑/删除 | 只读模式，避免数据误操作 |
