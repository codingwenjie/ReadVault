# 个人编码偏好规则

## 代码风格
1. **简洁精简**：代码保持简洁，去除冗余逻辑和不必要的注释
2. **TypeScript 优先**：使用 TS 类型约束，定义统一接口类型，确保类型安全

## 布局与样式
3. **弹性自适应**：页面布局采用响应式设计，适配 PC/平板/移动端

## 功能实现
4. **导出格式**：优先支持 Markdown 格式，其次 TXT 格式
5. **日志管理**：调试日志精简输出，正式环境关闭多余 console

## 架构原则
6. **离线优先**：优先实现本地离线可用逻辑，弱化强服务端依赖
7. **组件复用**：公共逻辑抽取为组件或工具函数，避免重复代码
8. **错误处理**：所有外部请求必须增加异常捕获和超时处理
